# QE Scrim — Team Management

PUBG Mobile স্ক্রিম টিম, স্ট্যান্ডিংস এবং পেমেন্ট ম্যানেজমেন্টের জন্য পূর্ণাঙ্গ ওয়েবসাইট।
Supabase (ডাটাবেজ) + Vercel Serverless Functions (সিকিউরিটি) + Telegram Bot (নোটিফিকেশন) দিয়ে বানানো।

## ১. আগের প্রজেক্ট থেকে কী আলাদা করা হয়েছে (সিকিউরিটি ফিক্স)

আগের মেস ম্যানেজমেন্ট প্রজেক্টে `ADMIN_PASS`, Supabase key, এবং Telegram bot token — সবকিছু সরাসরি
`index.html`-এর জাভাস্ক্রিপ্টে লেখা ছিল। এর মানে যেকেউ ব্রাউজারের "View Source" বা Dev Tools খুলে
এডমিন পাসওয়ার্ড এবং বট টোকেন দেখে ফেলতে পারতো, এবং নিজে থেকেই ডাটাবেজ এডিট করতে পারতো।

এই প্রজেক্টে:
- এডমিন পাসওয়ার্ড **কখনোই ব্রাউজারে পাঠানো হয় না**। লগইনের সময় পাসওয়ার্ড সার্ভারে (`/api/admin-login`) যাচাই হয়,
  আর সঠিক হলে একটি সাইন করা (signed) সাময়িক টোকেন ব্রাউজারে দেওয়া হয়।
- ডাটাবেজে যেকোনো এডিট/ডিলিট শুধু `/api/admin-write`-এর মাধ্যমে হয়, যেখানে প্রতিবার টোকেন যাচাই হয়, এবং
  আসল ডাটাবেজ পরিবর্তন হয় **Supabase Service Role Key** দিয়ে — যা সবসময় সার্ভারে (Vercel) গোপন থাকে, ব্রাউজারে কখনো যায় না।
- ব্রাউজার শুধুমাত্র Supabase Anon Key দিয়ে ডাটা **পড়তে (read)** পারে — কোনো লেখা/এডিট/ডিলিট সরাসরি ব্রাউজার থেকে সম্ভব না,
  কারণ Supabase-এ Row Level Security (RLS) চালু করে শুধু "SELECT" পলিসি রাখা হয়েছে।
- Telegram bot token শুধু সার্ভার সাইড ফাংশনে থাকে, ব্রাউজারে কখনো আসে না।

## ২. Supabase সেটআপ

1. [supabase.com](https://supabase.com) এ গিয়ে একটা নতুন প্রজেক্ট বানান।
2. SQL Editor-এ গিয়ে এই রিপোর `supabase-schema.sql` ফাইলের পুরো কোডটা রান করুন।
3. **Storage** ট্যাবে গিয়ে `payment-proofs` নামে একটা নতুন **Public bucket** বানান (পেমেন্ট স্ক্রিনশট রাখার জন্য)।
   তারপর SQL Editor-এ এই পলিসিটা রান করুন (schema ফাইলের নিচে কমেন্ট করা আছে):
   ```sql
   create policy "anon can upload payment proofs"
   on storage.objects for insert
   with check (bucket_id = 'payment-proofs');
   ```
4. প্রজেক্ট সেটিংস থেকে **Settings → API** এ গিয়ে এই তিনটা মান কপি করুন:
   - Project URL → `SUPABASE_URL`
   - `anon` `public` key → `SUPABASE_ANON_KEY`
   - `service_role` key (⚠️ এটা কখনো কারো সাথে শেয়ার করবেন না) → `SUPABASE_SERVICE_ROLE_KEY`

## ৩. Telegram Bot সেটআপ

1. Telegram-এ `@BotFather` কে মেসেজ দিন, `/newbot` কমান্ড দিয়ে একটা বট বানান। এটা আপনাকে একটা টোকেন দিবে
   (যেমন `123456:ABC-DEF...`) — এটাই `TG_BOT_TOKEN`।
2. আপনার বটকে টেলিগ্রামে মেসেজ দিন (`/start`), তারপর `@userinfobot`-কে মেসেজ দিয়ে নিজের numeric Chat ID বের করুন
   — এটাই `TG_CHAT_ID`।
3. একাধিক এডমিন চাইলে `TG_CHAT_ID` কমা দিয়ে একাধিক আইডি দেওয়া যাবে (কোড আপডেট লাগবে, বললে করে দিবো)।

## ৪. .env ফাইল — কই বসাবেন, কী নামে

### লোকাল কম্পিউটারে টেস্ট করতে চাইলে:
রুট ফোল্ডারে `.env.example` ফাইলটাকে কপি করে `.env` নামে সেভ করুন, এবং প্রতিটা মান নিজের তথ্য দিয়ে পূরণ করুন।
টার্মিনালে:
```
npm install
npx vercel dev
```

### Vercel-এ লাইভ করতে চাইলে (এটাই মূল উপায়):
1. এই প্রজেক্ট GitHub-এ পুশ করুন।
2. [vercel.com](https://vercel.com) এ গিয়ে GitHub রিপো ইম্পোর্ট করুন।
3. **Settings → Environment Variables**-এ গিয়ে `.env.example`-এর প্রতিটা নাম (key) বসিয়ে তার আসল মান দিন:

   | Key | কোথা থেকে পাবেন |
   |---|---|
   | `SUPABASE_URL` | Supabase → Settings → API |
   | `SUPABASE_ANON_KEY` | Supabase → Settings → API |
   | `SUPABASE_SERVICE_ROLE_KEY` | Supabase → Settings → API |
   | `ADMIN_PASSWORD` | নিজে একটা শক্তিশালী পাসওয়ার্ড ঠিক করুন |
   | `SESSION_SECRET` | টার্মিনালে চালান: `openssl rand -hex 32` |
   | `CALLBACK_SECRET` | আবার চালান: `openssl rand -hex 32` (উপরেরটার চেয়ে আলাদা হতে হবে) |
   | `TG_BOT_TOKEN` | BotFather থেকে |
   | `TG_CHAT_ID` | userinfobot থেকে |
   | `SMS_WEBHOOK_SECRET` | আবার একটা `openssl rand -hex 32` |

4. Deploy চাপুন। ব্যাস, সাইট লাইভ হয়ে যাবে।

## ৫. bKash পেমেন্ট ভেরিফিকেশন — দুইটা সিস্টেম

**কোনো official bKash API লাগবে না** — bKash পার্সোনাল/এজেন্ট নাম্বারের জন্য পাবলিক API নেই।
তাই দুইটা রাস্তা রাখা হয়েছে:

### A) ম্যানুয়াল ভেরিফাই (এখনই কাজ করবে)
ইউজার টাকা পাঠিয়ে সাইটে নাম, পরিমাণ, TrxID, স্ক্রিনশট সাবমিট করবে → এটা সরাসরি আপনার Telegram বটে
Approve/Reject বাটনসহ চলে যাবে → বাটনে চাপলেই Supabase-এ status আপডেট হয়ে যাবে। এক্সট্রা কোনো সেটআপ লাগবে না।

### B) স্বয়ংক্রিয় (Auto) ভেরিফাই — SMS ফরওয়ার্ড করে
bKash থেকে আসা SMS নিজে থেকে সাইটে পাঠানোর কোনো official উপায় নেই, কিন্তু এভাবে করা যায়:
1. যে ফোনে bKash SMS আসে (এডমিনের ফোন), সেখানে একটা SMS-forwarding অ্যাপ ইন্সটল করুন
   (যেমন: **Macrodroid**, **Tasker**, বা Play Store-এর "SMS Forwarder — Text Message Forwarding" অ্যাপ)।
2. অ্যাপে একটা নিয়ম বানান: bKash থেকে SMS আসলে সেটার টেক্সট এই URL-এ POST করবে:
   `https://আপনার-ডোমেইন.vercel.app/api/sms-webhook`
   Body/JSON: `{ "secret": "আপনার SMS_WEBHOOK_SECRET", "message": "<পুরো SMS টেক্সট>" }`
3. সার্ভার SMS থেকে amount, sender number, TrxID বের করে, কারো pending পেমেন্টের সাথে (নাম্বার + এমাউন্ট)
   মিললে সেটা **নিজে থেকেই approve** করে দিবে এবং Telegram-এ কনফার্মেশন পাঠাবে।

এই দুইটা সিস্টেম পাশাপাশি চলবে — auto না মিললেও, ম্যানুয়াল অপশন সবসময় থাকবে।

## ৬. ফাইল স্ট্রাকচার

```
qe-scrim/
├── public/
│   ├── index.html          ← পুরো ওয়েবসাইট (সব পেজ, ভ্যানিলা JS)
│   └── assets/logo.jpg, logo-transparent.png
├── api/
│   ├── config.js            ← ব্রাউজারকে পাবলিক Supabase key দেয়
│   ├── admin-login.js        ← পাসওয়ার্ড যাচাই করে টোকেন দেয়
│   ├── admin-write.js        ← সব এডমিন এডিট/ডিলিট এখান দিয়ে যায়
│   ├── payment-submit.js     ← যেকেউ পেমেন্ট সাবমিট করতে পারে
│   ├── telegram-callback.js  ← টেলিগ্রামের Approve/Reject বাটনের লিংক
│   └── sms-webhook.js        ← SMS ফরওয়ার্ডিং অ্যাপ থেকে আসা রিকোয়েস্ট
├── lib/server.js            ← শেয়ার করা হেল্পার ফাংশন
├── supabase-schema.sql
├── .env.example
└── package.json
```

## ৭. এখন যা যা আছে (Overview)

- **ড্যাশবোর্ড** — মোট টিম, ম্যাচ, ফান্ড, পেন্ডিং পেমেন্ট + সাম্প্রতিক অ্যাক্টিভিটি
- **টিম** — প্রতি টিমে ৮ জন (৪ মূল + ৪ রিজার্ভ/৫ম), টিম ম্যানেজারের নাম/IGN/নাম্বার (কপি আইকনসহ)
- **স্ট্যান্ডিংস** — একাধিক ম্যাচ যোগ করা যাবে, প্রতি ম্যাচে পজিশন+কিল বসালে অটো পয়েন্ট ক্যালকুলেট হয়ে
  ওভারঅল র‍্যাংকিং টেবিল বানায় (পজিশন পয়েন্ট টেবিল এডমিন নিজের মতো এডিট করতে পারবে)
- **পেমেন্ট** — bKash নাম্বার (কপি আইকনসহ), পেমেন্ট সাবমিশন ফর্ম (স্ক্রিনশটসহ), ম্যানুয়াল+অটো (SMS) ভেরিফিকেশন
- **অ্যাক্টিভিটি লগ** — কে কী এডিট করলো তার হিস্ট্রি
- QE থিমে (কালো + লাল) ডিজাইন, লোগো ব্যবহার করা হয়েছে, angular/cut-corner কার্ড, কাস্টম টোস্ট/মোডাল
  (ব্রাউজারের ডিফল্ট alert/confirm কোথাও ব্যবহার করা হয়নি)
- Developer credit (LinkedIn + GitHub লিংকসহ) সবসময় উপরে দেখা যাবে
- পুরোপুরি রেসপন্সিভ, Tailwind CDN দিয়ে বানানো তাই কোনো build step ছাড়াই যেকোনো ব্রাউজার/webview-তে চলবে

## ৮. যা এখনো নিজে যোগ করতে হবে বা জানিয়ে দিলে পরের ধাপে করে দিবো

- SMS ফরওয়ার্ডিং অ্যাপের real-world টেস্ট (bKash-এর SMS ফরম্যাট মাঝেমাঝে অপারেটরভেদে সামান্য আলাদা হতে পারে,
  টেস্ট করে দেখে regex টিউন করা লাগতে পারে)
- একাধিক এডমিনের জন্য আলাদা আলাদা লগইন (এখন একটাই শেয়ার্ড এডমিন পাসওয়ার্ড আছে)
- আপনার পরের রিকোয়ারমেন্টগুলো — বললেই ধাপে ধাপে যোগ করে দিবো
